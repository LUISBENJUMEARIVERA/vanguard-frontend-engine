## ⚡ 1-COMMAND GLOBAL INSTALLATION

### 🌐 Via skills.sh (Universal Agent Skills Directory)
Compatible across Claude Code, Cursor, Codex, OpenCode, and Antigravity:
```bash
npx skills add LUISBENJUMEARIVERA/vanguard-frontend-engine -g
```

### 🍎 Linux & macOS (Direct Bash / Zsh)
```bash
curl -fsSL https://raw.githubusercontent.com/LUISBENJUMEARIVERA/vanguard-frontend-engine/main/install.sh | bash
```

### 🪟 Windows (Direct PowerShell)
```powershell
irm https://raw.githubusercontent.com/LUISBENJUMEARIVERA/vanguard-frontend-engine/main/install.ps1 | iex
```

*Or from local clone:*
```powershell
.\install.ps1
```

## 🏛️ THE ANTI-GENERIC UI MANIFESTO

Vanguard Frontend Engine enforces non-negotiable styling directives and layout boundaries on every agentic frontend session:

| Pattern / Element | Status | Architectural Rationale |
| :--- | :--- | :--- |
| **Purple-to-Blue Gradients** (`#6366f1` / `#3b82f6`) | ❌ **STRICTLY BANNED** | Overused AI cliché found across thousands of lazy SaaS templates. |
| **Centered Hero with Twin Action Buttons** | ❌ **STRICTLY BANNED** | Lacks spatial tension, asymmetry, and intentional visual hierarchy. |
| **True Void Canvas `#08080a`** | ✅ **MANDATORY** | High-frequency contrast without the dull eye strain of washed-out grays. |
| **Surgical Acid Accents (`#d4ff00`, `#00f5ff`, `#ff4d00`)** | ✅ **STANDARD** | Radical focal anchors engineered for high-energy contrast. |
| **Console Micro-telemetry & Monospace HUDs** | ✅ **STANDARD** | Tactile, high-performance, military-grade software aesthetic. |

---

## 🧬 4 SIGNATURE ARCHETYPES

1. **Kinetic Scroll-driven:** Non-linear spring dynamics, liquid typography responding to scroll momentum, and reactive subtle 3D transforms.
2. **Editorial Brutalism:** Exposed 1px structural dividing lines, raw grid matrices without defensive padding, oversized bold typography.
3. **Swiss Precision:** Strict mathematical grid alignment, monochromatic high contrast, and rigorous geometric micro-spacing.
4. **Dark Cyberpunk:** Deep `#08080a` backdrop, hyper-contrasting acid phosphor highlights, and real-time console status telemetry.

---

## 🩺 3-TIER DIAGNOSTIC INTAKE PROTOCOL

When triggered, the skill strictly calibrates requirements prior to writing any frontend component:
1. **Visual Style Archetype:** Kinetic / Brutalism / Swiss / Cyberpunk.
2. **Frontend Architecture:** Astro + React / Next.js (App Router) / Vite / Modern Vanilla.
3. **Motion Intensity:** Brutal Minimal (0-10%) / Controlled Friction (30-50%) / Kinetic Overload (80-100%).
