## ⚡ 1-COMMAND GLOBAL INSTALLATION

Instala la skill directamente en el directorio global de **Google Antigravity** (`~/.gemini/antigravity/skills/`):

### 🍎 Linux & macOS (Bash / Zsh)
```bash
curl -fsSL https://raw.githubusercontent.com/vanguard-frontend/vanguard-engine/main/install.sh | bash
```

### 🪟 Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/vanguard-frontend/vanguard-engine/main/install.ps1 | iex
```

*O si clonaste este repositorio localmente:*
```powershell
.\install.ps1
```

## 🧬 4 ARQUETIPOS DE VANGUARDIA

1. **Kinetic Scroll-driven:** Dinámicas no lineales, tipografía líquida que responde a inercia de scroll y micro-perspectiva 3D.
2. **Brutalismo Editorial:** Retículas expuestas con líneas de 1px, matrices asimétricas, escala tipográfica sobredimensionada.
3. **Minimalismo Suizo:** Precisión geométrica absoluta, orden radical monocromático y microespaciado riguroso.
4. **Dark Cyberpunk:** Lienzo `#08080a`, acentos de fósforo ácido de alto contraste y widgets HUD en tiempo real.

---

## 🩺 PROTOCOLO DE DIAGNÓSTICO (3 PREGUNTAS)

Al activarse en Antigravity, la skill siempre ejecuta este cuestionario previo a la generación de código:
1. **Estilo Visual:** Kinetic / Brutalismo / Suizo / Cyberpunk.
2. **Stack Frontend:** Astro + React / Next.js / Vite / Vanilla.
3. **Nivel de Animación:** Minimal (0-10%) / Controlled Friction (30-50%) / Kinetic Overload (80-100%).
